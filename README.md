# 罗经 · 掌中天地

以紫金星云、悬浮灵兽卡牌和五层罗盘，探索传统文化中的符号、天文与历法。

这是一个可直接静态部署的前端项目。所有排盘、抽牌、注释和摄像头手势识别都在浏览器本地执行，不需要后端或 API 密钥。

## 功能

- **自由立体罗盘**：五层展开与合拢、双轴 360° 视角、惯性转盘、滚轮和双指缩放；支持 Three.js 和 Canvas 后备渲染。
- **四种主题**：周易罗经、二十八星宿、二十四节气、六十甲子。
- **九术问卜殿**：塔罗、奇门遁甲、大六壬、金口诀、六爻、金钱卦、小六壬、梅花易数、雷诺曼。
- **注释**：六十四卦原文、白话主题、字词注、本卦与变卦、动爻位置提示，以及可展开的生成过程。
- **手势控制**：剪刀手抬高展开、握拳收合、张掌挥动旋转；摄像头画面在本地处理。
- **本次记录**：内存保留最近 20 条，刷新页面即清空；支持复制结果和返回立体罗盘。
- **动态画面**：星点流动、刻度扫光、符纹与卡牌悬浮，并提供动效开关与减少动态偏好支持。

## 快速启动

需要 Node.js 20 或更新版本。首次下载依赖资源需要网络连接。

```bash
npm run setup
npm test
npm start
```

打开 `http://127.0.0.1:4173`，选择主罗盘或右上角的“九术问卜”。也可以直接打开 `/readings.html`。

无需执行 `npm install`：下载脚本仅使用 Node.js 内置模块。第三方脚本、WASM 和模型会下载到 `dist/vendor/`，每个文件都校验固定的 SHA-256。

摄像头需要 HTTPS 或 localhost，以及使用者明确允许摄像头权限。关闭手势或隐藏页面时会停止摄像头。

## 静态部署

先运行 `npm run setup`，然后把完整的 `dist/` 上传到任意支持 HTTPS 的静态托管服务。`dist/vendor/` 是运行必需资源；它们不提交到 Git，由下载脚本准备。

仓库提供 GitHub Pages 的手动部署工作流。在仓库设置中将 Pages 的发布源设为 **GitHub Actions**，再手动运行 **Deploy Pages**。下载失败或校验不一致会停止部署，不会跳过资源检查。

## 方法范围

| 方法 | 实现范围 |
| --- | --- |
| 塔罗 | 完整 78 张牌，不放回抽取三张，可选正逆位；原创符号卡面与反思注释。 |
| 雷诺曼 | 完整 36 张象征牌，三牌联想，不使用塔罗正逆位。 |
| 金钱卦 | 三枚铜钱各取 2/3，六次自下而上成卦；6/9 为动爻，支持手动录入。 |
| 六爻 | 本变卦、动爻、八宫、纳支五行、六亲、六神、世应；不作旺衰、伏神与用神判断。 |
| 梅花易数 | 三数体验式：前两数定上下卦，三数之和定动爻；含互卦参照。 |
| 小六壬 | 大安起正月、月上起日、日上起时的常见掌诀，门派与古本存在异例。 |
| 奇门遁甲 | **基础地盘**：手选阴阳遁和局数；无天盘、九星、八门、值符值使。 |
| 大六壬 | **天地盘与四课基础**：月将加时、日干寄宫；不含九宗门三传和天将。 |
| 金口诀 | **四位基础组课**：人元用五子遁、将神取地分上神；贵神手动录入。 |

这些结果用于传统文化阅读和自我反思。白话注释是编辑性释义；动爻说明是位置提示，不是该爻爻辞的逐字注解。三种基础术式不应被理解为完整专业排盘或未来事实判断。

日历按北京时间处理，不作真太阳时修正。节气时刻由 lunar-javascript 换算。星点连线与等分扇区是示意设计，不是实测星图。

## 项目结构

```text
dist/
  index.html           # 立体罗盘
  app.js               # 渲染、操作和手势
  readings.html        # 九术问卜殿
  readings.js          # 表单与结果展示
  divination.js        # 生成与基础排盘算法
  hex-notes.js         # 六十四卦白话注释
  card-data.js         # 78 / 36 张牌资料
  atlas-data.js        # 四主题资料与节气时间
  data.js              # 卦序、八卦、干支等基础资料
  vendor/              # setup 自动下载，不提交到 Git
scripts/
  fetch-vendor.mjs     # 固定版本下载与校验
  vendor-manifest.json # 来源地址与 SHA-256
  serve.mjs            # 本地静态服务
verify.mjs
verify-readings.mjs
```

## 校验

`npm test` 覆盖六十四卦映射、384 次爻位翻转、4,096 种铜钱结果、八宫世应、九宫地盘、四课古籍例、完整卡牌列表及节气日期。

已检查 Canvas 渲染与桌面、手机布局。测试环境没有实体摄像头，也未启用 WebGL，真实手势与 WebGL 效果需要在兼容设备上验证。
